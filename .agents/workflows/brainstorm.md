# Brainstorm Workflow

Use the `dandi-brainstorm` skill.

## Steps

1. Read `AGENTS.md` and relevant shared docs only if needed.
2. Clarify goal, constraints, users, and non-goals.
3. Compare viable approaches and tradeoffs.
4. Recommend a direction.
5. End with the next workflow: `/plan`, `/execute`, or `/audit`.

## Boundary

Read-only. Do not edit, stage, commit, or push.
